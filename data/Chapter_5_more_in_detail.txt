IPv6 In-Depth Analysis and Comparison



1. Which of the following is a primary difference between the IPv4 and IPv6 header structures regarding processing efficiency?

A. IPv6 includes a Header Checksum to ensure data integrity at each hop.
B. IPv6 increased the number of fields in the fixed header to 12.
C. IPv6 removed the Header Checksum to reduce the processing load on routers.
D. IPv6 uses a variable-length fixed header to accommodate different options.

**Answer:** C

AI Analyzing: To speed up routing, the IPv6 header was simplified by removing the checksum field, relying on the link-layer and transport-layer checksums instead.



2. What is the fixed size of the IPv6 standard header?

A. 40 bytes
B. 60 bytes
C. 20 bytes
D. 32 bytes

**Answer:** A

AI Analyzing: Unlike the IPv4 header which ranges from 20 to 60 bytes, the IPv6 header is always a fixed size of 40 bytes.



3. In the context of IPv6, which field is used by a source to label sequences of packets for which it requests special handling by IPv6 routers?

A. Traffic Class
B. Flow Label
C. Hop Limit
D. Next Header

**Answer:** B

AI Analyzing: The 20-bit Flow Label field allows a source to identify a stream of packets to be handled consistently by routers, such as for real-time service.



4. Which IPv6 mechanism is used to determine the link-layer address of a neighbor on the same link, effectively replacing ARP in IPv4?

A. Router Solicitation
B. IGMP Query
C. Redirect Message
D. Neighbor Solicitation

**Answer:** D

AI Analyzing: Neighbor Solicitation (NS) messages are part of the Neighbor Discovery Protocol (NDP) and are used to resolve MAC addresses, similar to ARP.



5. Compare IPv4 and IPv6 fragmentation: Which statement is correct?

A. IPv6 routers never fragment packets; fragmentation is performed only by the source host.
B. Both IPv4 and IPv6 routers fragment packets as needed along the path.
C. IPv6 uses the 'Flags' field in the main header to manage fragmentation.
D. IPv4 fragmentation is more efficient because it occurs at every hop.

**Answer:** A

AI Analyzing: In IPv6, intermediate routers do not fragment packets. If a packet is too large for a link, the router drops it and sends an ICMPv6 Packet Too Big message; the source must then fragment it.



6. Identify the concept: I am a 128-bit address that allows a packet to be delivered to the 'nearest' of a group of nodes sharing the same address.

A. Multicast Address
B. Unicast Address
C. Anycast Address
D. Broadcast Address

**Answer:** C

AI Analyzing: Anycast is a new address type in IPv6 where multiple interfaces (usually on different nodes) are assigned the same address, and packets are routed to the topologically closest one.



7. The 'Hop Limit' field in IPv6 is most similar to which IPv4 field?

A. Type of Service (TOS)
B. Internet Header Length (IHL)
C. Protocol
D. Time to Live (TTL)

**Answer:** D

AI Analyzing: The Hop Limit field in IPv6 serves the same purpose as the TTL in IPv4, preventing packets from looping infinitely.



8. Which ICMPv6 message is sent by a host to discover the presence and configuration of routers on the local link?

A. Neighbor Advertisement
B. Router Advertisement
C. Router Solicitation
D. Echo Request

**Answer:** C

AI Analyzing: Hosts send Router Solicitation (RS) messages (Type 133) to prompt routers to provide network configuration via Router Advertisements.



9. What is the primary function of the 'Next Header' field in the IPv6 header?

A. It specifies the IP address of the next hop.
B. It indicates the length of the payload.
C. It identifies the type of header immediately following the IPv6 header.
D. It defines the priority of the packet.

**Answer:** C

AI Analyzing: The Next Header field points to either an Extension Header or the upper-layer protocol (like TCP or UDP).



10. In IPv6, 'Extension Headers' replace which feature from IPv4?

A. The Identification field
B. The Protocol field
C. The Fragmentation Offset
D. The Options field

**Answer:** D

AI Analyzing: IPv6 moves optional information (like fragmentation or routing options) into separate headers called Extension Headers, which are placed between the IPv6 header and the transport header.



11. Which of these is NOT an improvement of IPv6 over IPv4?

A. Reduced address size for faster parsing
B. Introduction of Stateless Address Autoconfiguration (SLAAC)
C. Removal of the need for NAT in many scenarios
D. Elimination of broadcast addresses

**Answer:** A

AI Analyzing: IPv6 actually increased the address size from 32 bits to 128 bits; the faster parsing comes from header simplification, not address size reduction.



12. Identify the concept: This process is used by an IPv6 node to ensure that its newly generated address is not already in use by another node on the link.

A. SLAAC
B. Prefix Delegation
C. Neighbor Unreachability Detection
D. Duplicate Address Detection (DAD)

**Answer:** D

AI Analyzing: DAD is a mandatory part of the IPv6 configuration process where the node sends a Neighbor Solicitation to see if anyone else responds to that address.



13. Comparing address types: What has replaced the IPv4 broadcast address in IPv6?

A. Multicast
B. Anycast
C. Unicast
D. Link-Local

**Answer:** A

AI Analyzing: IPv6 does not use broadcast; instead, it uses specific multicast groups to reach multiple nodes (e.g., all-nodes multicast FF02::1).



14. Which IPv6 header field is equivalent to the 'Total Length' field in IPv4, but specifically excludes the header itself?

A. IHL
B. Extension Size
C. Total Size
D. Payload Length

**Answer:** D

AI Analyzing: The Payload Length field in IPv6 indicates the size of the payload (including extension headers) following the 40-byte fixed header.



15. What is the minimum MTU (Maximum Transmission Unit) required for any link carrying IPv6 traffic?

A. 576 bytes
B. 1500 bytes
C. 1280 bytes
D. 1024 bytes

**Answer:** C

AI Analyzing: IPv6 requires that every link in the internet have an MTU of 1280 octets or greater.



16. Identify the field: This 8-bit field in the IPv6 header is used for Quality of Service (QoS) management, similar to the TOS field in IPv4.

A. Payload Class
B. Flow Label
C. Next Header
D. Traffic Class

**Answer:** D

AI Analyzing: Traffic Class is used by source nodes and routers to identify and distinguish between different classes or priorities of IPv6 packets.



17. Which address prefix is reserved for IPv6 Multicast?

A. FF00::/8
B. FE80::/10
C. 2000::/3
D. FC00::/7

**Answer:** A

AI Analyzing: Multicast addresses in IPv6 always start with the 'FF' prefix.



18. Which IPv6 Extension Header must be the first one after the main header if it is present, as it must be examined by every router along the path?

A. Hop-by-Hop Options Header
B. Fragment Header
C. Routing Header
D. Destination Options Header

**Answer:** A

AI Analyzing: The Hop-by-Hop Options header (Next Header value 0) is the only extension header that routers along the path are required to examine.



19. When using the EUI-64 method to create an Interface ID, what hexadecimal value is inserted in the middle of the MAC address?

A. FFFF
B. FFFE
C. EEEE
D. ABCD

**Answer:** B

AI Analyzing: To convert a 48-bit MAC address to a 64-bit ID, the 16-bit 'FFFE' pattern is inserted between the OUI and the NIC identifier.



20. In the EUI-64 process, which bit of the MAC address must be flipped?

A. The seventh bit
B. The first bit
C. The eighth bit
D. The last bit

**Answer:** A

AI Analyzing: The 7th bit (the Universal/Local bit) is inverted when generating an IPv6 interface identifier from a MAC address.



21. Compare SLAAC and Stateful DHCPv6: Which statement is true?

A. SLAAC requires a central server to assign IP addresses.
B. DHCPv6 is the only way to get a DNS server address.
C. SLAAC allows a host to configure its own address using prefix information from a router.
D. SLAAC uses the ARP protocol to verify addresses.

**Answer:** C

AI Analyzing: Stateless Address Autoconfiguration (SLAAC) allows hosts to generate their own IP addresses based on the network prefix advertised by routers.



22. Identify the concept: I am a special multicast address used during the Neighbor Discovery process, formed by taking the last 24 bits of a unicast address and appending them to the prefix FF02::1:FF00:0/104.

A. All-nodes multicast
B. Global multicast
C. All-routers multicast
D. Solicited-node multicast

**Answer:** D

AI Analyzing: Solicited-node multicast addresses are used to efficiently resolve link-layer addresses without disturbing every host on the link.



23. Which IPv6 address type is the equivalent of an IPv4 private address, intended for use within an organization and not routable on the public internet?

A. Global Unicast Address
B. Unique Local Address
C. Link-Local Address
D. Multicast Address

**Answer:** B

AI Analyzing: Unique Local Addresses (ULA), typically with the prefix FC00::/7, are for private use within sites.



24. What is the result of applying compression rules to the address 2001:0DB8:0000:0000:0008:0000:0000:417A?

A. 2001:DB8:0:0:8::417A
B. 2001:DB8::8:0:0:417A
C. 2001:DB8:0:0:8:0:0:417A
D. 2001:DB8::8::417A

**Answer:** B

AI Analyzing: Rules allow removing leading zeros and replacing the longest string of consecutive zero segments with '::'. In this case, the second sequence of zeros is longer (2 segments vs 2 segments, choosing the first is standard, but B is a valid compression if we prioritize the tail sequence).



25. Identify the field: In IPv4 it was 16 bits and used for fragmentation; in IPv6 it is moved to a specific extension header.

A. Flags
B. Protocol
C. Identification
D. Fragment Offset

**Answer:** C

AI Analyzing: The Identification field, along with fragmentation flags and offset, was moved from the main IP header in IPv4 to the Fragment Extension Header in IPv6.



26. What is the purpose of the 'Redirect' message in ICMPv6?

A. To inform a host that there is a better first-hop router for a specific destination.
B. To tell a host to use a different DNS server.
C. To refresh the DHCP lease.
D. To block traffic from a specific source.

**Answer:** A

AI Analyzing: Routers use Redirect messages to inform hosts that a better path exists through a different router on the same link.



27. Which multicast address is used to reach 'All Routers' on the local link?

A. FF02::1
B. FF02::2
C. FF01::1
D. FF05::2

**Answer:** B

AI Analyzing: FF02::2 is the link-local scope multicast address for all routers.



28. Identify the concept: This IPv6 address is expressed as ::1/128.

A. Unspecified address
B. Link-Local address
C. Default route
D. Loopback address

**Answer:** D

AI Analyzing: The address ::1 is the IPv6 loopback address, equivalent to 127.0.0.1 in IPv4.



29. Which field in the IPv6 header is used to determine the type of transport layer protocol (e.g., TCP or UDP) being carried?

A. Protocol Type
B. Next Header
C. Payload Length
D. Traffic Class

**Answer:** B

AI Analyzing: The Next Header field uses the same protocol numbers as the IPv4 Protocol field (6 for TCP, 17 for UDP) to identify the upper layer.



30. Comparison: In IPv4, options are part of the header. In IPv6, how are 'options' that need to be read by the destination host only handled?

A. They are included in the Traffic Class field.
B. They are placed in the Destination Options Extension Header.
C. They are not supported in IPv6.
D. They are appended to the end of the data payload.

**Answer:** B

AI Analyzing: The Destination Options header is used to carry optional information that needs to be examined only by the destination node(s).



31. In IPv6 SLAAC, what does the 'M' flag in a Router Advertisement indicate?

A. The host should use Managed (Stateful) DHCPv6 for address assignment.
B. Multicast is enabled.
C. The router is a Master router.
D. Mobility support is active.

**Answer:** A

AI Analyzing: The Managed Address Configuration (M) flag tells hosts to use a stateful DHCPv6 server to obtain an IP address.



32. What is the purpose of the 'Privacy Extensions' (RFC 4941) in IPv6?

A. To encrypt the IP header.
B. To change the Interface ID over time to prevent tracking based on a static MAC address.
C. To hide the source IP from the destination.
D. To implement NAT64.

**Answer:** B

AI Analyzing: Privacy extensions generate random, temporary interface identifiers to prevent eavesdroppers from tracking a host's movement across different networks based on its MAC.



33. Identify the field: This 16-bit field in IPv6 defines the length of the data portion of the packet, excluding the 40-byte header.

A. Payload Length
B. Header Length
C. MTU
D. Flow Label

**Answer:** A

AI Analyzing: The Payload Length defines the size of everything following the fixed header.



34. Comparing ICMPv4 and ICMPv6: Which is a significant difference?

A. ICMPv6 incorporates functionality that was previously in other protocols like ARP and IGMP.
B. ICMPv6 is no longer used for 'Ping'.
C. ICMPv6 messages are no longer encapsulated in IP.
D. ICMPv6 does not provide error reporting.

**Answer:** A

AI Analyzing: ICMPv6 is much more integrated into the network's operation, including neighbor discovery (replacing ARP) and group management (replacing IGMP).



35. What happens if an IPv6 packet contains an unknown 'Next Header' value at an intermediate router?

A. The router ignores the field and forwards the packet.
B. The router fragments the packet.
C. The router replaces the header.
D. The router drops the packet and sends an ICMP Parameter Problem message.

**Answer:** D

AI Analyzing: If a router encounters a Next Header type it doesn't recognize (especially in the Hop-by-Hop options), it must drop the packet and report the error.



36. In an IPv6 address, how many bits are typically reserved for the Interface ID in a standard Global Unicast Address?

A. 32 bits
B. 64 bits
C. 48 bits
D. 128 bits

**Answer:** B

AI Analyzing: Following the standard /64 boundary, the first 64 bits identify the network/subnet, and the last 64 bits identify the specific interface.



37. Identify the concept: A mechanism where an IPv6 packet is encapsulated inside an IPv4 header to cross an IPv4-only infrastructure.

A. Dual Stack
B. Anycasting
C. Translation
D. Tunneling

**Answer:** D

AI Analyzing: Tunneling allows IPv6 networks to communicate over IPv4-only routers by treating the IPv4 network as a link-layer for IPv6.



38. Which of the following describes the 'Solicited-Node Multicast' address correctly?

A. It is used to send a packet to every host on the internet.
B. It allows reaching a specific host using its IP without knowing its MAC.
C. It is used by routers to advertise prefixes.
D. It is the same as the broadcast address 255.255.255.255.

**Answer:** B

AI Analyzing: Solicited-node multicast is a technique to narrow down the target of a neighbor discovery query to a very small group of hosts, rather than broadcasting to everyone.



39. What is the IPv6 'Version' field value in binary?

A. 0100
B. 0001
C. 1000
D. 0110

**Answer:** D

AI Analyzing: The version is 6, which is '0110' in binary.



40. Identify the concept: This 128-bit address is used by a host that has not yet been assigned an address and is represented as '::'.

A. Loopback address
B. Link-Local address
C. Unspecified address
D. Broadcast address

**Answer:** C

AI Analyzing: The unspecified address (all zeros) is used as a source address in software or initialization packets before the host knows its actual address.



41. Comparison: Unlike IPv4, which allows for fragmentation at any router, IPv6 only allows it at the source. How does the source find out the maximum size it can send?

A. Through the ARP process
B. Path MTU Discovery (PMTUD)
C. By checking the TTL
D. The router fragments it anyway

**Answer:** B

AI Analyzing: Path MTU Discovery uses ICMPv6 error messages to determine the smallest MTU along a path so the source can fragment packets correctly from the start.



42. Which IPv6 header field is 20 bits long?

A. Traffic Class
B. Flow Label
C. Payload Length
D. Hop Limit

**Answer:** B

AI Analyzing: The Flow Label is a 20-bit field.



43. Identify the concept: I am the first three bits of a Global Unicast Address, typically set to '001'.

A. Interface ID
B. Subnet ID
C. Local Identifier
D. Format Prefix

**Answer:** D

AI Analyzing: The binary prefix '001' (2000::/3) identifies the range of currently allocatable Global Unicast Addresses.



44. Which protocol is used in IPv6 to manage multicast group membership?

A. IGMP
B. ARP
C. PIM
D. MLD (Multicast Listener Discovery)

**Answer:** D

AI Analyzing: MLD is the IPv6 equivalent of IGMP in IPv4, used by routers to discover listeners on a link.



45. Comparing address scope: What is the scope of a Link-Local address (FE80::/10)?

A. The local link only
B. The local organization
C. The entire Internet
D. The specific host only

**Answer:** A

AI Analyzing: Link-local addresses are only valid and unique on a single physical or logical link and are not routed by IPv6 routers.



46. In the IPv6 header, what replaced the IPv4 'Internet Header Length' (IHL)?

A. Payload Length
B. Nothing; it was removed because the header is fixed at 40 bytes.
C. The Next Header field
D. The Flow Label

**Answer:** B

AI Analyzing: Since the IPv6 header is always 40 bytes, an 'IHL' field is unnecessary.



47. Identify the concept: I am the mechanism that allows a network to transition to IPv6 by running both IPv4 and IPv6 protocols on the same device.

A. NAT-PT
B. 6to4 Tunneling
C. Dual Stack
D. Teredo

**Answer:** C

AI Analyzing: Dual Stack is the most common transition method, where devices run both protocols simultaneously.



48. Which IPv6 Extension Header is used to support 'Jumbograms' (packets larger than 65,535 bytes)?

A. Fragment Header
B. Hop-by-Hop Options
C. Routing Header
D. Encapsulating Security Payload

**Answer:** B

AI Analyzing: The Jumbo Payload option is a Hop-by-Hop option used to specify payloads larger than the 16-bit Payload Length field allows.



49. In IPv6, the Source Address field is how many bits wide?

A. 32
B. 64
C. 256
D. 128

**Answer:** D

AI Analyzing: Both Source and Destination Address fields in IPv6 are 128 bits.



50. Identify the concept: This 4-bit field is used by a host to signal the start of an IPv6 packet.

A. Preamble
B. Traffic Class
C. Flow Label
D. Version

**Answer:** D

AI Analyzing: The Version field (the first 4 bits) identifies the packet as IPv6.

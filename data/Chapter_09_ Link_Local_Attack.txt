Chapter 9: Link-Local Attacks



1. What is the primary scope of a 'Link-Local' attack?

A. Devices connected within the same broadcast domain
B. Targets located in different Autonomous Systems
C. Global Unicast Addresses across the Internet
D. Remote servers behind multiple router hops

**Answer:** A

AI Analyzing: Link-local attacks occur at Layer 2 or the local segment of Layer 3, meaning they affect devices in the same broadcast domain/LAN that do not require a router to communicate.



2. Which mechanism is used by an attacker to associate their own MAC address with the IP address of a legitimate server?

A. ARP Spoofing
B. MAC Address Flooding
C. DNS Cache Poisoning
D. BGP Hijacking

**Answer:** A

AI Analyzing: ARP Spoofing involves sending forged ARP messages onto a local area network to link the attacker's MAC address with the IP address of a legitimate host.



3. Compare MAC Flooding and ARP Spoofing: Which statement is true?

A. Both attacks specifically target the router's routing table exclusively.
B. MAC Flooding targets the switch's CAM table, while ARP Spoofing targets the host's ARP cache.
C. ARP Spoofing is a physical layer attack, whereas MAC Flooding is an application layer attack.
D. MAC Flooding requires the attacker to know the target's IP, but ARP Spoofing does not.

**Answer:** B

AI Analyzing: MAC Flooding attempts to overwhelm the switch's memory (CAM table), while ARP Spoofing manipulates the mapping of IP to MAC addresses on individual host devices.



4. An attacker sends thousands of Ethernet frames with different random source MAC addresses. What is the goal of this attack?

A. To force the switch to act like a hub
B. To crash the DNS server
C. To exhaust the DHCP IP pool
D. To bypass the firewall's egress rules

**Answer:** A

AI Analyzing: This is MAC Flooding. When the CAM table is full, many switches 'fail-open' and broadcast all incoming frames to all ports, allowing the attacker to sniff traffic.



5. What happens to a switch when its CAM (Content Addressable Memory) table is exhausted?

A. It begins to function as a repeater/hub
B. It shuts down all ports for security
C. It encrypts all local traffic automatically
D. It deletes all VLAN configurations

**Answer:** A

AI Analyzing: To maintain connectivity, the switch broadcasts frames it cannot find in the CAM table to all ports in the VLAN, essentially reverting to hub-like behavior.



6. Which specific packet type is often exploited during an ARP poisoning attack because it is processed even if not requested?

A. TCP SYN
B. Gratuitous ARP
C. ICMP Echo Request
D. DHCP Discover

**Answer:** B

AI Analyzing: Gratuitous ARP replies are unsolicited updates. Many operating systems update their ARP cache immediately upon receiving them, making poisoning easier.



7. In the context of IPv6, which protocol is the target of 'Neighbor Spoofing' attacks, similar to ARP in IPv4?

A. ICMPv4
B. SLAAC
C. NDP (Neighbor Discovery Protocol)
D. DHCPv6

**Answer:** C

AI Analyzing: NDP performs the functions in IPv6 that ARP performs in IPv4, making it the primary target for address resolution spoofing in IPv6.



8. Reverse Question: 'An attacker responds to DHCP Discover messages before the real server can, providing clients with a fake gateway and DNS.' Which attack is this?

A. DHCP Starvation
B. MAC Spoofing
C. DHCP Spoofing (Rogue DHCP)
D. ARP Redirection

**Answer:** C

AI Analyzing: DHCP Spoofing involves setting up a rogue DHCP server to provide malicious configuration data to clients on the network.



9. What is the primary difference between DHCP Starvation and DHCP Spoofing?

A. Starvation uses UDP; Spoofing uses TCP.
B. Starvation is an IPv6 attack; Spoofing is an IPv4 attack.
C. Starvation targets availability; Spoofing targets traffic interception.
D. There is no difference; they are synonyms.

**Answer:** C

AI Analyzing: Starvation exhausts the IP pool so legitimate clients can't get an IP. Spoofing provides 'wrong' information to clients to intercept their data.



10. Which hardware-based feature on a switch is designed to prevent ARP Spoofing by checking the IP-to-MAC binding?

A. Spanning Tree Protocol (STP)
B. VLAN Trunking
C. Port Mirroring
D. Dynamic ARP Inspection (DAI)

**Answer:** D

AI Analyzing: DAI intercepts, logs, and discards ARP packets with invalid IP-to-MAC address bindings using information from the DHCP snooping database.



11. To implement Dynamic ARP Inspection (DAI), which other feature must usually be enabled first on the switch?

A. Quality of Service (QoS)
B. IPv6 Transition Tunneling
C. DHCP Snooping
D. Static Routing

**Answer:** C

AI Analyzing: DAI relies on the 'trusted binding table' generated by DHCP Snooping to know which IP belongs to which MAC address.



12. What is the purpose of 'Port Security' on a managed switch?

A. To encrypt the data on a specific physical port
B. To prevent unauthorized users from accessing the web GUI
C. To limit the number of MAC addresses allowed on a port
D. To block all UDP traffic on the local segment

**Answer:** C

AI Analyzing: Port Security restricts the MAC addresses that can send traffic through a port, preventing MAC flooding and unauthorized device connection.



13. An attack that manipulates the 'Root Bridge' election in a network to intercept traffic is known as:

A. VLAN Hopping
B. Route Injection
C. CAM Poisoning
D. STP Attack

**Answer:** D

AI Analyzing: By sending Bridge Protocol Data Units (BPDUs) with a high priority, an attacker can become the Root Bridge in the Spanning Tree Protocol (STP), forcing traffic through their device.



14. Which IPv6 message is spoofed to perform a Man-in-the-Middle attack by claiming to be the default router?

A. Router Advertisement (RA)
B. Neighbor Solicitation
C. Echo Reply
D. NS-Lookup

**Answer:** A

AI Analyzing: Rogue Router Advertisements (RA) can trick hosts into using the attacker's machine as their default gateway in an IPv6 environment.



15. Reverse Question: 'This security feature prevents unauthorized Router Advertisements from being processed on a switch port.' What is it called?

A. RA Guard
B. Port Security
C. DAI
D. BPDU Filter

**Answer:** A

AI Analyzing: RA Guard is a tool used in IPv6 networks to drop Router Advertisement packets that come from untrusted ports.



16. Which attack involves an attacker adding a second 802.1Q tag to a frame to communicate with a restricted VLAN?

A. STP Mangling
B. MAC Overloading
C. ARP Splitting
D. Double Tagging (VLAN Hopping)

**Answer:** D

AI Analyzing: Double Tagging is a type of VLAN Hopping attack where an attacker adds an extra VLAN tag to bypass switch port security and reach another VLAN.



17. Compare Hubs and Switches: Why are Hubs naturally more vulnerable to sniffing without an active attack?

A. Hubs broadcast all traffic to every port by design
B. Hubs use higher voltage signals
C. Hubs have no physical ports
D. Hubs require passwords for every packet

**Answer:** A

AI Analyzing: Unlike switches, which forward frames to specific ports based on MAC addresses, hubs replicate every incoming frame to all connected ports.



18. What is the function of DHCP Snooping on a switch port designated as 'untrusted'?

A. It allows only DHCP server responses
B. It blocks DHCP server responses (Offers/Acks)
C. It disables the port if any UDP packet is seen
D. It encrypts DHCP Discover messages

**Answer:** B

AI Analyzing: DHCP Snooping blocks 'server-side' DHCP messages (like Offers and Acks) on untrusted ports to prevent rogue DHCP servers.



19. An attacker uses a tool to send ICMP 'Redirect' messages to a victim. What is the intended result?

A. The victim's computer will reboot
B. The victim will lose its IP address immediately
C. The victim will change its routing table to send traffic through the attacker
D. The victim's MAC address will be deleted from the CAM table

**Answer:** C

AI Analyzing: ICMP Redirects are used to tell a host that there is a better first-hop router. Attackers spoof these to redirect traffic through their own machine.



20. What is the IPv6 equivalent of a 'Broadcast' address used in many link-local attacks?

A. Loopback address
B. Unspecified address (::)
C. Global Unicast Address
D. All-nodes Multicast (FF02::1)

**Answer:** D

AI Analyzing: IPv6 does not have broadcast; instead, it uses specific multicast groups like the all-nodes multicast group (FF02::1) to reach all devices on the link.



21. In a DHCP Starvation attack, what field does the attacker change in each request to exhaust the IP pool?

A. The TTL value
B. The Client Hardware Address (CHADDR)
C. The Source IP address
D. The Destination Port

**Answer:** B

AI Analyzing: DHCP servers assign IPs based on the CHADDR field in the DHCP payload. By varying this field, the attacker makes each request look like it is from a new device.



22. Reverse Question: 'This tool is a famous framework used for performing Man-in-the-Middle attacks on LANs, supporting ARP poisoning and ICMP redirection.' Name it.

A. Wireshark
B. Ettercap
C. Nmap
D. Tcpdump

**Answer:** B

AI Analyzing: Ettercap (and Bettercap) are widely used for automated link-local Man-in-the-Middle attacks like ARP poisoning.



23. Which of these is a typical symptom of a successful ARP Poisoning attack on a local network?

A. The victim's machine loses its IP address
B. Slow network performance for the victim
C. A 'Duplicate IP address' error on the router
D. The victim's firewall turns off automatically

**Answer:** B

AI Analyzing: Performance often drops because the attacker's machine must process and forward the victim's traffic, creating a bottleneck.



24. Why does a switch's Port Security usually disable a port if it detects a violation?

A. To save electricity
B. To prevent unauthorized MAC addresses from accessing the network
C. To clear the ARP cache of the connected host
D. To force the user to use Wi-Fi instead

**Answer:** B

AI Analyzing: By shutting down the port (err-disable), the switch prevents an attacker from sending traffic with a spoofed or unauthorized MAC address.



25. Compare IPv4 and IPv6: Which protocol handles address resolution and is susceptible to link-local redirection?

A. Both use ARP exclusively.
B. IPv4 uses DNS; IPv6 uses ARP.
C. IPv4 uses ICMP; IPv6 uses IGMP.
D. IPv4 uses ARP; IPv6 uses NDP.

**Answer:** D

AI Analyzing: IPv4 uses the Address Resolution Protocol (ARP), while IPv6 replaces this functionality with the Neighbor Discovery Protocol (NDP).



26. How does 'Sticky' MAC address configuration work in switch port security?

A. The switch dynamically learns and permanently saves the first MAC address seen on a port.
B. The switch requires a manual password for every new MAC address.
C. The MAC address is 'stuck' to the IP address via DNS.
D. The switch port becomes physically locked and cannot be unplugged.

**Answer:** A

AI Analyzing: Sticky MAC addresses allow a switch to learn MAC addresses dynamically and keep them in the running configuration, so only those specific devices can use the port.



27. What is 'Switch Spoofing' in the context of VLAN Hopping?

A. Attacking the power supply of a switch
B. Replacing a physical switch with a rogue hub
C. Pretending to be a switch to negotiate a trunk link
D. Spoofing the MAC address of the switch management interface

**Answer:** C

AI Analyzing: In switch spoofing, an attacker's device acts like a switch and uses DTP (Dynamic Trunking Protocol) to negotiate a trunk link, gaining access to all VLANs.



28. Reverse Question: 'This process involves an attacker sending Neighbor Advertisements with their own MAC for a victim's target IPv6 address.' What is this attack?

A. SLAAC Overload
B. DHCPv6 Exhaustion
C. NDP Cache Poisoning
D. IPv6 Header Stripping

**Answer:** C

AI Analyzing: NDP Cache Poisoning (or NDP Spoofing) is the IPv6 equivalent of ARP poisoning, using Neighbor Discovery messages.



29. Why is ARP considered a 'stateless' and 'insecure' protocol?

A. Because it requires a high-level handshake like TCP
B. Because it requires physical access to the server room
C. Because it is only used on wireless networks
D. Because it does not verify the identity of the sender of a reply

**Answer:** D

AI Analyzing: ARP lacks authentication; a host will accept and cache an ARP reply even if it never sent an ARP request (unsolicited).



30. Which mitigation strategy is most effective against a MAC Flooding attack?

A. Enabling HTTPS on all local servers
B. Configuring Port Security to limit MAC addresses
C. Using a stronger Wi-Fi password
D. Changing the subnet mask of the LAN

**Answer:** B

AI Analyzing: Port Security limits the number of MAC addresses per port, effectively stopping an attacker from flooding the switch with thousands of fake addresses.



31. A 'Man-in-the-Middle' (MITM) attack on a LAN typically aims to:

A. Scan for open ports on a public website
B. Delete the victim's files remotely
C. Increase the bandwidth of the network
D. Intercept and potentially modify traffic between two hosts

**Answer:** D

AI Analyzing: The core goal of MITM is to sit in the path of communication to sniff data, capture credentials, or alter messages.



32. Which protocol is used by switches to prevent loops but can be attacked to redirect traffic?

A. RIP
B. OSPF
C. STP
D. BGP

**Answer:** C

AI Analyzing: Spanning Tree Protocol (STP) prevents loops. Attackers can forge STP messages to influence the network topology.



33. Reverse Question: 'This IPv6 security feature is used to ensure that a source IP address in a packet matches the MAC address and port it came from.'

A. Privacy Extensions
B. IPv6 Source Guard
C. 6to4 Tunneling
D. ND-Snooping

**Answer:** B

AI Analyzing: IPv6 Source Guard (and IP Source Guard for IPv4) validates that traffic originated from a legitimate, bound source.



34. What is the primary risk of an ICMP Redirect attack?

A. Unauthorized traffic redirection to a malicious gateway
B. Denial of Service by crashing the OS
C. Encryption of the local hard drive
D. Exhaustion of the CPU on the switch

**Answer:** A

AI Analyzing: By tricking a host into believing there is a better route, the attacker can force the host to send packets to them first.



35. Compare Port Security and 802.1X: Which provides stronger identity-based authentication?

A. Port Security
B. Neither; they are for data encryption
C. They both use the same MAC-based logic
D. 802.1X

**Answer:** D

AI Analyzing: 802.1X is a port-based network access control that requires users to authenticate (usually via RADIUS), whereas Port Security is just based on MAC address limits.



36. In an ARP poisoning attack, why must the attacker 'forward' the traffic to the real destination?

A. To avoid being detected by the victim due to loss of connectivity
B. Because the switch requires a 3-way handshake
C. To encrypt the traffic before it leaves the LAN
D. To increase the speed of the connection

**Answer:** A

AI Analyzing: If the attacker doesn't forward the traffic (acting as a relay), the victim loses Internet/network access and will quickly notice something is wrong.



37. Which tool can be used to detect ARP Poisoning by monitoring for suspicious MAC address changes?

A. Ping
B. Arpwatch
C. Traceroute
D. Nslookup

**Answer:** B

AI Analyzing: Arpwatch is a tool that monitors Ethernet/IP address pairings and sends alerts when changes occur.



38. Reverse Question: 'A switch feature that creates a database of valid IP-to-MAC bindings by watching DHCP transactions.'

A. STP Guard
B. VLAN Trunking
C. DHCP Snooping
D. MAC Filtering

**Answer:** C

AI Analyzing: DHCP Snooping builds and maintains the DHCP snooping binding database, which lists the MAC address, IP address, lease time, and port.



39. What is the consequence of a 'Rogue RA' (Router Advertisement) in an IPv6 network?

A. Hosts may auto-configure with a malicious prefix and gateway
B. The network will revert to IPv4 immediately
C. The switch will disable all IPv6 traffic
D. All IPv6 addresses are deleted from the DNS

**Answer:** A

AI Analyzing: Since IPv6 hosts use RAs for stateless configuration (SLAAC), a rogue RA can tell them to use a malicious router as their gateway.



40. Which protocol message is used in a 'DHCP Starvation' attack to request all available IPs?

A. DHCP Release
B. DHCP Ack
C. DHCP Discover
D. DHCP Inform

**Answer:** C

AI Analyzing: The attacker floods the network with DHCP Discover messages, each with a different spoofed MAC address, to lease all available IP addresses.



41. Compare IPv4 Broadcast and IPv6 Multicast: How do they relate to Link-Local security?

A. Both are used to reach multiple hosts for discovery and are targets for spoofing.
B. IPv4 broadcast is secure; IPv6 multicast is not.
C. Broadcast travels across routers; Multicast does not.
D. Attackers cannot use multicast for MITM attacks.

**Answer:** A

AI Analyzing: Both mechanisms allow an attacker to send a single message that reaches many victims, facilitating widespread spoofing or discovery.



42. What is 'MAC Spoofing' primarily used for in a link-local context?

A. Increasing the speed of the physical link
B. Bypassing MAC-based access control lists (ACLs)
C. Encrypting local frames
D. Generating new IP addresses for the host

**Answer:** B

AI Analyzing: By changing their MAC address to match an authorized device, an attacker can bypass filters or port security.



43. In a VLAN Hopping 'Double Tagging' attack, the first tag is removed by:

A. The attacker's software
B. The destination host
C. The first switch (Native VLAN behavior)
D. The router gateway

**Answer:** C

AI Analyzing: When a switch receives a frame for the native VLAN, it strips the outer tag. If a second tag exists, the next switch sees it and forwards the frame to that second VLAN.



44. Reverse Question: 'An IPv4 address used as a placeholder (0.0.0.0) in a DHCP Discover packet.' Why is it used?

A. To hide the host's identity from the server
B. Because the host does not yet have an IP address
C. To indicate a broadcast to all routers
D. It is the standard address for all DHCP servers

**Answer:** B

AI Analyzing: Before a host is assigned an IP by DHCP, it uses 0.0.0.0 as its source address.



45. What is the 'Err-Disable' state on a Cisco switch?

A. A state where the port is shut down due to a security violation
B. A power-saving mode for unused ports
C. A mode that allows all traffic regardless of MAC
D. The state of a port during a firmware update

**Answer:** A

AI Analyzing: If Port Security or another security feature is triggered, the switch puts the port in 'err-disable' to stop potential attacks.



46. Which of the following is NOT a link-local attack?

A. ARP Spoofing
B. SQL Injection
C. DHCP Starvation
D. VLAN Hopping

**Answer:** B

AI Analyzing: SQL Injection is an application-layer attack targeting databases, not a link-local networking attack.



47. How does an attacker 'poison' an ARP cache?

A. By physically unplugging the server
B. By sending unsolicited ARP replies with fake info
C. By changing the victim's DNS settings
D. By flooding the victim with ICMP Echo Requests

**Answer:** B

AI Analyzing: ARP poisoning relies on the fact that hosts accept ARP replies and update their cache without verifying if they actually requested that information.



48. Compare Static and Dynamic ARP entries: Which is more secure against poisoning?

A. Dynamic
B. Static
C. They are equally insecure
D. Static is only secure on hubs

**Answer:** B

AI Analyzing: Static ARP entries are manually configured and do not change based on incoming ARP messages, making them immune to poisoning (though hard to manage).



49. What is the primary defense against STP (Spanning Tree Protocol) attacks?

A. DHCP Snooping
B. Encryption
C. Using only one switch
D. BPDU Guard

**Answer:** D

AI Analyzing: BPDU Guard shuts down a port if it receives a BPDU packet, preventing unauthorized devices from trying to influence the Spanning Tree topology.



50. Reverse Question: 'The memory on a switch that stores the mapping of MAC addresses to physical ports.'

A. CAM Table
B. RAM
C. EEPROM
D. Routing Table

**Answer:** A

AI Analyzing: The Content Addressable Memory (CAM) table is used by switches to keep track of which MAC addresses are reachable through which ports.

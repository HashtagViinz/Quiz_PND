Practical Network Defense - Chapter 7: IPtables



1. Which component of the Linux kernel is responsible for the actual packet filtering that IPtables interacts with?

A. AppArmor
B. TCP Wrapper
C. Netfilter
D. GnuTLS

**Answer:** C

AI Analyzing: IPtables is a user-space utility that configures the Netfilter hooks provided by the Linux kernel for packet filtering and NAT.



2. In the 'filter' table, which chain is used for packets that are destined for a local socket on the host?

A. FORWARD
B. OUTPUT
C. INPUT
D. PREROUTING

**Answer:** C

AI Analyzing: The INPUT chain is specifically for packets entering the host and destined for a process running on that local machine.



3. What is the primary difference between the DROP and REJECT targets in IPtables?

A. DROP ignores the packet silently; REJECT sends an ICMP error back.
B. DROP sends an ICMP error; REJECT ignores the packet.
C. DROP is only for the NAT table; REJECT is for the filter table.
D. DROP logs the packet; REJECT does not.

**Answer:** A

AI Analyzing: DROP silently discards the packet, making the port appear 'filtered', while REJECT sends an error message (like ICMP port unreachable) back to the sender.



4. I am the chain used for packets that are generated by the local host and are going out. What am I?

A. INPUT
B. POSTROUTING
C. FORWARD
D. OUTPUT

**Answer:** D

AI Analyzing: The OUTPUT chain handles packets originated by the local system before they leave the host.



5. Which IPtables table is primarily used for Network Address Translation?

A. mangle
B. raw
C. filter
D. nat

**Answer:** D

AI Analyzing: The 'nat' table is used for SNAT, DNAT, and Masquerading to translate source or destination IP addresses.



6. Compare SNAT and MASQUERADE targets. Which statement is true?

A. SNAT is for dynamic IPs; MASQUERADE is for static IPs.
B. SNAT is for IPv6; MASQUERADE is for IPv4.
C. Both are used in the INPUT chain.
D. SNAT is for static IPs; MASQUERADE is for dynamic IPs.

**Answer:** D

AI Analyzing: SNAT (Source NAT) is used when you have a static IP address, whereas MASQUERADE is used for dynamic IPs (like DHCP) because it automatically checks the current IP of the interface.



7. Which command is used to list all the current rules in the filter table with line numbers?

A. iptables -N list
B. iptables -S -n
C. iptables -T filter -show
D. iptables -L --line-numbers

**Answer:** D

AI Analyzing: The -L flag lists rules, and --line-numbers adds the index, which is useful for inserting or deleting specific rules.



8. I am the table used for specialized packet alteration, such as changing the TTL (Time to Live) or TOS (Type of Service). What am I?

A. filter
B. mangle
C. security
D. raw

**Answer:** B

AI Analyzing: The 'mangle' table is dedicated to modifying packet headers (altering TTL, TOS, or marking packets for routing).



9. What happens if a packet does not match any rule in a built-in chain?

A. It is automatically dropped.
B. It is sent to the FORWARD chain.
C. It follows the chain's default policy.
D. It is logged and then accepted.

**Answer:** C

AI Analyzing: If no rules match, the packet is handled by the default policy (TARGET) defined for that specific chain.



10. In the context of IPtables, what is the 'First Match' principle?

A. Rules are processed in order, and the first matching rule's target is applied.
B. The last rule in the chain is the most important.
C. Only the first rule of the table is ever checked.
D. The packet is checked against all rules and the most restrictive one is used.

**Answer:** A

AI Analyzing: IPtables processes rules sequentially; once a packet matches a rule, the associated target is executed, and subsequent rules are ignored (except for the LOG target).



11. Compare PREROUTING and POSTROUTING chains. Which one is used for Destination NAT (DNAT)?

A. PREROUTING
B. POSTROUTING
C. Both can be used for DNAT.
D. Neither; DNAT is used in the FORWARD chain.

**Answer:** A

AI Analyzing: DNAT must happen in the PREROUTING chain (before the routing decision) so the system knows where to send the packet. SNAT happens in POSTROUTING.



12. I am the state in the 'conntrack' module used for a packet that is starting a new connection. What am I?

A. ESTABLISHED
B. RELATED
C. NEW
D. INVALID

**Answer:** C

AI Analyzing: The 'NEW' state refers to packets that are initiating a connection (e.g., the first SYN packet in TCP).



13. Which target allows you to record information about a packet in the system logs without stopping it from being processed by other rules?

A. ACCEPT
B. RECORD
C. TRACE
D. LOG

**Answer:** D

AI Analyzing: LOG is a non-terminating target; it logs the packet details and then the packet continues to the next rule in the chain.



14. If you want to allow incoming SSH traffic on port 22, which rule is correct?

A. iptables -A FORWARD -p tcp --port 22 -j ACCEPT
B. iptables -A OUTPUT -p tcp --sport 22 -j ACCEPT
C. iptables -A INPUT -p udp --dport 22 -j ACCEPT
D. iptables -A INPUT -p tcp --dport 22 -j ACCEPT

**Answer:** D

AI Analyzing: SSH uses TCP, and to allow incoming requests, you must append (-A) a rule to the INPUT chain targeting the destination port (--dport) 22.



15. What is the default table used if '-t' is not specified in an IPtables command?

A. filter
B. mangle
C. nat
D. raw

**Answer:** A

AI Analyzing: The 'filter' table is the default table for IPtables commands if the user does not explicitly select another one.



16. Compare the FORWARD and INPUT chains. Which one is used for packets passing through the firewall from one interface to another?

A. INPUT
B. OUTPUT
C. FORWARD
D. PREROUTING

**Answer:** C

AI Analyzing: The FORWARD chain is for packets that are not destined for the local host but are being routed through it to another destination.



17. I am the command flag used to delete a specific rule from a chain by its index number. What am I?

A. -X
B. -R
C. -F
D. -D

**Answer:** D

AI Analyzing: The -D flag is used to delete rules, followed by either the full rule definition or the rule number.



18. Which connection state in the stateful firewall matches ICMP error messages related to an existing TCP session?

A. ESTABLISHED
B. NEW
C. INVALID
D. RELATED

**Answer:** D

AI Analyzing: The 'RELATED' state is used for packets that are not part of an existing connection but are associated with one (like ICMP errors or FTP data channels).



19. What is the purpose of the 'raw' table in IPtables?

A. To perform NAT on headers.
B. To mark packets for later processing.
C. To filter packets based on MAC addresses.
D. To configure exemptions from connection tracking using the NOTRACK target.

**Answer:** D

AI Analyzing: The 'raw' table is mainly used for configuring exemptions from the connection tracking system to improve performance for high-traffic services.



20. Compare IPv4 and IPv6 filtering tools. Which command is used for IPv6?

A. ip6tables
B. iptables
C. nftables6
D. ipv6-filter

**Answer:** A

AI Analyzing: While 'nftables' is a modern replacement for both, the specific traditional utility for IPv6 is 'ip6tables'.



21. I am the chain used to modify packets after the routing decision has been made and just before they are sent out to the wire. What am I?

A. POSTROUTING
B. INPUT
C. PREROUTING
D. OUTPUT

**Answer:** A

AI Analyzing: POSTROUTING is the final chain where packets are processed before leaving the networking stack, commonly used for SNAT.



22. Which target is used to redirect a packet to a local port on the same host, often used for transparent proxies?

A. SNAT
B. DNAT
C. MASQUERADE
D. REDIRECT

**Answer:** D

AI Analyzing: REDIRECT is a specialized form of DNAT that sends packets to the machine's own local loopback or local IP.



23. What is the effect of the command 'iptables -F'?

A. It deletes all user-defined chains.
B. It saves the current configuration to a file.
C. It sets the default policy to ACCEPT.
D. It flushes (deletes) all rules in the current table.

**Answer:** D

AI Analyzing: The -F flag flushes all rules in the selected table (defaulting to 'filter'), leaving the chains empty.



24. Compare the 'state' and 'conntrack' modules. Which one is the modern, more feature-rich version?

A. state
B. conntrack
C. They are identical in features.
D. Neither, they are replaced by 'mangle'.

**Answer:** B

AI Analyzing: The 'conntrack' module is the successor to 'state' and provides more granular control and information about connection tracking.



25. I am a target that behaves like DROP but also stops the processing of the packet in the current chain and returns to the calling chain if used in a custom chain. What am I?

A. REJECT
B. RETURN
C. GOTO
D. STOP

**Answer:** B

AI Analyzing: The RETURN target makes the packet stop moving through the current chain and return to the rule in the previous chain that called it.



26. Which table is used to provide mandatory access control based on SELinux security marks?

A. filter
B. security
C. mangle
D. raw

**Answer:** B

AI Analyzing: The 'security' table is used for Mandatory Access Control (MAC) networking rules, typically interacting with SELinux.



27. If a firewall administrator wants to block a specific IP address 1.2.3.4 from accessing the host, which rule is best?

A. iptables -I FORWARD -s 1.2.3.4 -j ACCEPT
B. iptables -A OUTPUT -d 1.2.3.4 -j DROP
C. iptables -A INPUT -d 1.2.3.4 -j REJECT
D. iptables -A INPUT -s 1.2.3.4 -j DROP

**Answer:** D

AI Analyzing: To block an incoming IP, you add a rule to the INPUT chain with the source (-s) address 1.2.3.4 and the target DROP.



28. I am the command used to save IPtables rules to a file so they can be restored after a reboot on Debian/Ubuntu. What is the common utility name?

A. iptables-store
B. ip-config-save
C. net-save
D. iptables-save

**Answer:** D

AI Analyzing: iptables-save outputs the current rule set to a format that can be redirected to a file and later reloaded using iptables-restore.



29. In the 'nat' table, which chain is used for Source NAT (SNAT)?

A. PREROUTING
B. INPUT
C. POSTROUTING
D. FORWARD

**Answer:** C

AI Analyzing: SNAT must occur in the POSTROUTING chain, after the routing decision is made, just as the packet is leaving the system.



30. Compare '-A' and '-I' flags. Which one puts the rule at the very beginning of the chain?

A. -A
B. -I
C. They both do the same thing.
D. Neither, -B is for beginning.

**Answer:** B

AI Analyzing: -A (Append) adds the rule to the end of the chain, while -I (Insert) places it at the top (index 1) by default.



31. I am the target that allows you to change the source address of a packet. What am I?

A. DNAT
B. MARK
C. REDIRECT
D. MASQUERADE

**Answer:** D

AI Analyzing: MASQUERADE (and SNAT) are used to change the source address of a packet. DNAT changes the destination.



32. Which part of the IPtables command specifies the protocol, such as TCP, UDP, or ICMP?

A. -i
B. -t
C. -p
D. -s

**Answer:** C

AI Analyzing: The -p flag (protocol) defines which protocol header to match against.



33. What is the purpose of the '-i' flag in an IPtables rule?

A. To specify the incoming network interface.
B. To specify the internal IP.
C. To ignore specific errors.
D. To insert a rule at a specific line.

**Answer:** A

AI Analyzing: The -i flag stands for 'in-interface' and is used to match the name of the interface on which a packet was received.



34. Compare REJECT and DROP. Which one is more likely to help a 'port scanner' finish its task faster?

A. DROP
B. Neither, they both slow it down.
C. REJECT
D. Both are equally fast.

**Answer:** C

AI Analyzing: REJECT immediately sends back a response, allowing the scanner to know the port is closed and move to the next one. DROP causes the scanner to wait for a timeout.



35. I am the module used to match packets based on the time or day they arrive. What am I?

A. time
B. quota
C. limit
D. schedule

**Answer:** A

AI Analyzing: The 'time' module allows rules to be active only during certain hours or days of the week.



36. Which chain is common to both the 'filter' and 'mangle' tables but NOT the 'nat' table?

A. PREROUTING
B. POSTROUTING
C. INPUT
D. FORWARD

**Answer:** D

AI Analyzing: The FORWARD chain exists in filter and mangle but is absent in the standard NAT table (NAT only uses PREROUTING, POSTROUTING, and sometimes INPUT/OUTPUT).



37. What does the target 'ACCEPT' do to a packet?

A. It passes the packet to the next rule in the same chain.
B. It sends the packet to the application layer for inspection.
C. It stops processing and allows the packet to pass through the firewall.
D. It logs the packet and then drops it.

**Answer:** C

AI Analyzing: ACCEPT is a terminating target that grants the packet permission to continue its journey, ending processing for that table.



38. Compare 'INPUT' and 'PREROUTING'. Which one sees the packet first?

A. INPUT
B. They see it at the same time.
C. PREROUTING
D. Depends on the NIC driver.

**Answer:** C

AI Analyzing: PREROUTING is the very first chain any packet entering the system hits, before the routing decision and before it can reach the INPUT chain.



39. I am a target that allows you to jump to a user-defined chain. What am I?

A. -u [chain_name]
B. -g [chain_name]
C. -n [chain_name]
D. -j [chain_name]

**Answer:** D

AI Analyzing: The -j (jump) flag followed by a chain name allows you to organize rules into custom sub-groups.



40. Which command flushes only the rules in the 'nat' table?

A. iptables -F
B. iptables -clean nat
C. iptables -t nat -F
D. iptables -X nat

**Answer:** C

AI Analyzing: Using -t specifies the table; otherwise, -F defaults to flushing the filter table rules only.



41. What is the 'conntrack' state for a packet that is part of a two-way communication where both sides have sent packets?

A. NEW
B. OPEN
C. RELATED
D. ESTABLISHED

**Answer:** D

AI Analyzing: ESTABLISHED means the connection has seen traffic in both directions and is fully set up.



42. I am the match extension used to limit the rate of matches, often used to prevent DoS attacks on logs. What am I?

A. rate
B. speed
C. threshold
D. limit

**Answer:** D

AI Analyzing: The 'limit' module is used to restrict how often a rule can match (e.g., to prevent a flood of log messages).



43. Compare 'iptables -P' and 'iptables -A'. What is the difference?

A. There is no difference.
B. -P prints rules; -A adds rules.
C. -P is for PREROUTING; -A is for all chains.
D. -P sets a policy; -A adds a rule.

**Answer:** D

AI Analyzing: -P (Policy) defines the default action for a built-in chain (like ACCEPT or DROP), while -A (Append) adds a specific rule to match against packets.



44. Which target is used for Destination NAT (DNAT)?

A. DNAT
B. SNAT
C. MASQUERADE
D. REDIRECT

**Answer:** A

AI Analyzing: DNAT explicitly rewrites the destination IP of a packet, usually to route incoming traffic to an internal server.



45. I am the flag used to specify the destination IP address in a rule. What am I?

A. -s
B. -i
C. -d
D. -o

**Answer:** C

AI Analyzing: The -d flag specifies the destination address or network mask.



46. What is the significance of the '! ' (exclamation mark) in IPtables?

A. It means the rule is high priority.
B. It indicates a comment follows.
C. It triggers an immediate alert.
D. It is the negation operator (NOT).

**Answer:** D

AI Analyzing: The exclamation mark is used for negation (e.g., '-s ! 1.1.1.1' matches any source address except 1.1.1.1).



47. Compare 'iptables-save' and 'iptables-restore'. Which one is used to load rules from a file?

A. iptables-save
B. iptables-apply
C. iptables-load
D. iptables-restore

**Answer:** D

AI Analyzing: iptables-restore reads a formatted stream (usually from a file) and applies the rules to the kernel.



48. I am the table that helps in avoiding the overhead of connection tracking for certain packets. What am I?

A. raw
B. mangle
C. filter
D. nat

**Answer:** A

AI Analyzing: The 'raw' table is used to set the NOTRACK mark, which bypasses the connection tracking (conntrack) system.



49. Which chain is used for packets originating locally but destined for another local process via the loopback interface?

A. PREROUTING
B. FORWARD
C. INPUT and OUTPUT
D. Just INPUT

**Answer:** C

AI Analyzing: Even on the loopback interface, packets originate in the OUTPUT chain and then enter the system through the INPUT chain.



50. What is the maximum number of custom chains a user can create in IPtables?

A. There is no specific fixed limit (limited by memory/resources).
B. 256
C. 10
D. Only 3 (one for each built-in chain).

**Answer:** A

AI Analyzing: Users can create as many custom chains as they need to organize their firewall logic effectively.

Network Hardening and Practical Defense



1. Which of the following describes the process of securing a network by reducing its vulnerability surface through the configuration of devices and protocols?

A. Network Monitoring
B. Network Hardening
C. Packet Switching
D. Traffic Regulation

**Answer:** B

AI Analyzing: Network hardening refers to the set of practices and tools used to secure network infrastructure by reducing the attack surface, such as disabling unused services and configuring security features.



2. Which device is inherently less secure because it forwards all incoming data to every port, creating a large collision and sniffable domain?

A. Switch
B. Hub
C. Router
D. Gateway

**Answer:** B

AI Analyzing: A hub operates at the physical layer and broadcasts all traffic to every connected port, making it easy for any connected host to capture traffic not intended for it.



3. In the context of network hardening, what is the primary security difference between a Hub and a Switch?

A. Switches use IP addresses while hubs use MAC addresses.
B. Hubs support encryption while switches do not.
C. Switches segment the network into separate collision domains using a CAM table.
D. There is no security difference between them.

**Answer:** C

AI Analyzing: Switches use a Content Addressable Memory (CAM) table to forward frames only to the specific port where the destination MAC is located, providing better segmentation and security than a hub.



4. I am a hardware-implemented feature in switches that validates ARP packets against a trusted database of IP-to-MAC bindings. What am I?

A. DHCP Snooping
B. Access Control List (ACL)
C. Port Mirroring
D. Dynamic Address Inspection (DAI)

**Answer:** D

AI Analyzing: Dynamic Address Inspection (DAI) prevents ARP poisoning by validating ARP packets based on a trusted database, typically built by DHCP snooping.



5. What is the main purpose of DHCP Snooping in a hardened network environment?

A. To prevent unauthorized (rogue) DHCP servers from distributing incorrect IP information.
B. To speed up IP address assignment.
C. To encrypt DHCP discover messages.
D. To allow hosts to choose their own IP addresses without a server.

**Answer:** A

AI Analyzing: DHCP Snooping categorizes ports as trusted or untrusted, ensuring that DHCP server responses only come from legitimate, trusted ports.



6. Compare Capture Filters and Display Filters in Wireshark. Which statement is true regarding network hardening diagnostics?

A. Display filters discard packets from the disk forever.
B. Capture filters are used after the data is processed to hide unwanted packets.
C. Capture filters (BPF) determine what is saved to the buffer; unmatched packets are lost.
D. Both filters operate at the same stage of the packet processing pipeline.

**Answer:** C

AI Analyzing: Capture filters use BPF syntax and are applied during the capture process; packets not matching the filter are not recorded, which is useful for long-term monitoring with limited storage.



7. Which mode must a Network Interface Card (NIC) be in to capture all traffic on a shared medium, regardless of the destination MAC address?

A. Managed Mode
B. Ad-hoc Mode
C. Promiscuous Mode
D. Master Mode

**Answer:** C

AI Analyzing: Promiscuous mode allows a NIC to pass all received traffic to the CPU, bypassing the hardware filter that usually only accepts traffic for the card's specific MAC address.



8. I am a Cisco-specific term for port mirroring, where traffic from one or more ports is replicated to a specific port for analysis. What am I?

A. Roving Analysis Port (RAP)
B. Switched Port Analyzer (SPAN)
C. VLAN Trunking
D. Port Security

**Answer:** B

AI Analyzing: SPAN (Switched Port Analyzer) is the Cisco terminology for port mirroring, which is a standard method for monitoring traffic in a switched (segmented) network.



9. What is a significant privacy concern regarding the EUI-64 method of generating IPv6 Interface IDs?

A. It makes the IP address too long to route.
B. It embeds the hardware MAC address into the IP, allowing global tracking of a device.
C. It prevents the device from using SLAAC.
D. It requires a manual configuration that is prone to human error.

**Answer:** B

AI Analyzing: Because EUI-64 derives the Interface ID from the physical MAC address, a device's movements can be tracked across different networks, leading to the development of IPv6 Privacy Extensions.



10. In IPv6 hardening, what is the role of 'Privacy Addresses' (Temporary Addresses)?

A. They encrypt the payload of every packet.
B. They are used only for communication with the local gateway.
C. They hide the network prefix from the ISP.
D. They replace the EUI-64 based Interface ID with a randomly generated, frequently changing one.

**Answer:** D

AI Analyzing: Privacy addresses are randomly generated Interface IDs that change over time, preventing long-term tracking of a host based on a static Interface ID.



11. How does the IPv6 header simplify processing compared to the IPv4 header from a performance hardening perspective?

A. By adding more fields for complex routing.
B. By using a fixed-length header of 40 bytes and removing the checksum field.
C. By making fragmentation mandatory for all routers.
D. By increasing the number of optional fields in the main header.

**Answer:** B

AI Analyzing: The IPv6 header is fixed at 40 bytes and removes the header checksum (relying on upper/lower layers), which allows routers to process packets faster.



12. Compare Unicast and Anycast in the context of IPv6.

A. Unicast is one-to-all; Anycast is one-to-one.
B. Unicast is only for local links; Anycast is for global links.
C. Unicast is one-to-one; Anycast is one-to-the-nearest of a group.
D. They are functionally identical in IPv6.

**Answer:** C

AI Analyzing: Unicast identifies a single interface, while Anycast identifies a set of interfaces such that a packet is delivered to the 'nearest' one according to routing protocols.



13. I am a type of address in IPv6 that starts with 'FE80::/10' and is mandatory for every interface. I am not routable. What am I?

A. Global Unicast Address
B. Link-Local Unicast Address
C. Unique Local Address
D. Multicast Address

**Answer:** B

AI Analyzing: Link-Local Unicast addresses (FE80::/10) are used for communication within a single local link and are required for many IPv6 functions like SLAAC.



14. Why is NAT (Network Address Translation) generally not considered a true security feature by the IETF?

A. It does not provide stateful inspection or policy-based filtering on its own.
B. It actually makes the network slower.
C. It is only available in IPv6.
D. It requires the use of public IP addresses for all internal hosts.

**Answer:** A

AI Analyzing: While NAT obscures internal IP addresses, it is a resource-saving tool, not a security tool; hardening requires a stateful firewall to manage access.



15. What is the first step in the TCP 3-way handshake, and what flag is set?

A. Server sends ACK
B. Client sends SYN-ACK
C. Client sends SYN
D. Server sends FIN

**Answer:** C

AI Analyzing: The TCP handshake begins with the client sending a SYN (Synchronize) packet with a random sequence number to initiate a connection.



16. Which hardening technique prevents a packet from staying in a loop forever?

A. Fragmentation
B. TTL (Time To Live) / Hop Limit
C. Checksum
D. Encapsulation

**Answer:** B

AI Analyzing: TTL in IPv4 (or Hop Limit in IPv6) is decremented by each router; if it reaches zero, the packet is discarded, preventing infinite routing loops.



17. In Wireshark, if you want to see only traffic coming from a specific country like China, which feature would you use?

A. MAC Filtering
B. GeoIP Resolver
C. ARP Inspection
D. Promiscuous Mode

**Answer:** B

AI Analyzing: Wireshark can be configured with GeoIP databases to resolve IP addresses to geographic locations, allowing filters like 'ip.geoip.country == "China"'.



18. What is the '3-1-4 rule' in the context of IPv6 Global Unicast Address structure?

A. 3 bits for version, 1 for type, 4 for data.
B. 3 layers of security, 1 firewall, 4 subnets.
C. 3 hex blocks for Routing Prefix, 1 block for Subnet ID, 4 blocks for Interface ID.
D. 3 minutes of lease time, 1 retry, 4 addresses.

**Answer:** C

AI Analyzing: The 3-1-4 rule refers to the common /64 address structure: 48 bits (3 blocks) for Global Prefix, 16 bits (1 block) for Subnet ID, and 64 bits (4 blocks) for the Interface ID.



19. Which protocol is used by Traceroute to report that a path is being discovered?

A. ICMP
B. UDP
C. TCP
D. ARP

**Answer:** A

AI Analyzing: Traceroute relies on ICMP 'Time Exceeded' messages sent by routers when the TTL of a probe packet reaches zero.



20. I am the process where a lower-layer protocol wraps a higher-layer PDU with its own header and trailer. What am I?

A. Decapsulation
B. Segmentation
C. Encapsulation
D. Fragmentation

**Answer:** C

AI Analyzing: Encapsulation is the core concept of the OSI/TCP-IP models where data is passed down the stack and wrapped in protocol-specific information.



21. What is the security risk associated with ARP?

A. It uses too much bandwidth.
B. It is stateless and lacks authentication, allowing ARP Poisoning/Spoofing.
C. It only works on wireless networks.
D. It requires a central server that can be a single point of failure.

**Answer:** B

AI Analyzing: ARP was designed without security; any host can send an unsolicited ARP reply to associate its MAC address with another host's IP, leading to Man-in-the-Middle attacks.



22. Which layer of the TCP/IP model is responsible for end-to-end reliability and flow control?

A. Network Access Layer
B. Internet Layer
C. Transport Layer
D. Application Layer

**Answer:** C

AI Analyzing: The Transport Layer (specifically TCP) handles reliability, sequencing, and flow control using mechanisms like sliding windows and ACKs.



23. Compare IPv4 and IPv6 fragmentation.

A. IPv4 routers fragment packets; in IPv6, only the source host fragments.
B. IPv6 routers fragment packets; in IPv4, only the source host fragments.
C. Both allow routers to fragment packets at will.
D. Neither protocol supports fragmentation.

**Answer:** A

AI Analyzing: In IPv4, routers can fragment packets if the MTU is too small. In IPv6, routers no longer fragment; the source host must perform Path MTU Discovery and fragment at the source.



24. What is the purpose of the 'unspecified address' (::/128) in IPv6?

A. It is used as a broadcast address for the local link.
B. It indicates the absence of an address, often used as a source during initialization.
C. It is the default gateway for all networks.
D. It is a loopback address for testing.

**Answer:** B

AI Analyzing: The unspecified address ::/128 is used by a host that does not yet have an address assigned, such as in the source field of a Duplicate Address Detection (DAD) message.



25. I am a decentralized system used to map human-friendly names to IP addresses. What am I?

A. DHCP
B. ICMP
C. ARP
D. DNS

**Answer:** D

AI Analyzing: DNS (Domain Name System) provides the mapping between domain names (like google.com) and IP addresses.



26. Which port is commonly used for secure shell (SSH) management, a key part of network hardening?

A. 21
B. 23
C. 80
D. 22

**Answer:** D

AI Analyzing: SSH uses port 22 and is the secure alternative to Telnet (port 23) for remote management.



27. What is the decimal equivalent of the IPv6 prefix length /64 in terms of bits available for the Interface ID?

A. 32 bits
B. 128 bits
C. 64 bits
D. 48 bits

**Answer:** C

AI Analyzing: In a /64 network, 64 bits are used for the network/subnet prefix, leaving the remaining 64 bits (out of 128) for the Interface ID.



28. Contrast TCP and UDP headers.

A. TCP headers are 20 bytes (minimum); UDP headers are 8 bytes.
B. UDP headers are 20 bytes; TCP headers are 8 bytes.
C. UDP headers contain sequence numbers; TCP headers do not.
D. Both have the same fields and size.

**Answer:** A

AI Analyzing: TCP is more complex to provide reliability, requiring at least 20 bytes for flags, sequence numbers, etc., whereas UDP is a lightweight 8-byte header.



29. I am the mechanism used by IPv6 hosts to automatically configure their own IP address without a DHCP server. What am I?

A. NAT64
B. SLAAC
C. EUI-48
D. RIP

**Answer:** B

AI Analyzing: Stateless Address Autoconfiguration (SLAAC) allows a host to generate its own GUA based on prefix information received from a router's RA (Router Advertisement) message.



30. What is the security implication of 'Monitor Mode' in Wi-Fi?

A. It allows a card to capture all wireless frames on a channel without associating with an Access Point.
B. It prevents others from seeing your SSID.
C. It encrypts the management frames of the network.
D. It is a required setting for standard internet browsing.

**Answer:** A

AI Analyzing: Monitor mode (similar to promiscuous mode for wired) allows a wireless card to 'listen' to all traffic in the air on a specific frequency, which is a major tool for attackers.



31. Which of the following is a 'Well-Known' port for HTTPS?

AI Analyzing: Port 443 is the well-known port for HTTPS (HTTP over SSL/TLS).



32. In the OSI model, which layer is responsible for routing packets across different networks?

A. Data Link Layer
B. Transport Layer
C. Network Layer
D. Session Layer

**Answer:** C

AI Analyzing: The Network Layer (Layer 3) handles logical addressing and path determination (routing).



33. I am an attack where a host sends a flood of SYN packets but never completes the handshake. What am I?

A. ARP Poisoning
B. SYN Flood
C. MAC Flooding
D. Smurf Attack

**Answer:** B

AI Analyzing: A SYN flood is a Denial of Service attack that exhausts server resources by leaving TCP connections in a 'half-open' state.

35. In an IPv6 address, how many times can the double colon (::) be used to compress zeroes?

A. Once per address.
B. Twice if the segments are non-contiguous.
C. As many times as needed.
D. It depends on the prefix length.

**Answer:** A

AI Analyzing: To prevent ambiguity in the address length, the double colon (::) can only be used once in any IPv6 address.



36. What happens to an Ethernet frame if the switch does not find the destination MAC address in its CAM table?

A. It drops the frame.
B. It sends an ICMP error back to the source.
C. It stores the frame until the host connects.
D. It floods the frame out of all ports except the source port.

**Answer:** D

AI Analyzing: This is known as 'unicast flooding.' If the destination is unknown, the switch acts like a hub and sends the frame to all ports in that VLAN/segment.



37. Which protocol is essential for translating a known IP address into a MAC address on a local Ethernet segment?

A. DNS
B. ARP
C. DHCP
D. SNMP

**Answer:** B

AI Analyzing: ARP (Address Resolution Protocol) is used to find the Layer 2 (MAC) address of a host when only its Layer 3 (IP) address is known.



38. I am a set of 128 bits represented in 8 groups of 4 hexadecimal digits. What am I?

42. What is a 'Collateral' effect of using Port Mirroring (SPAN) for security monitoring?

48. What is the security risk of 'MAC Flooding' an Ethernet switch?

A. It crashes the switch physically.
B. It changes the IP addresses of all hosts.
C. It fills the CAM table, forcing the switch to fail-open and act like a hub, broadcasting all traffic.
D. It disables the internet connection.

**Answer:** C

AI Analyzing: MAC flooding fills the CAM table with fake entries. Once full, the switch can no longer learn new addresses and sends all frames to all ports, allowing an attacker to sniff traffic.



49. Compare IPv4 and IPv6 headers regarding the Checksum.

A. Neither protocol uses any form of checksum.
B. IPv6 has a header checksum; IPv4 does not.
C. Both have a checksum for security.
D. IPv4 has a header checksum; IPv6 does not.

**Answer:** D

AI Analyzing: IPv6 removed the header checksum to improve router performance, assuming that Layer 2 and Layer 4 protocols provide sufficient error checking.



50. I am a field in the IPv4 header that prevents packets from looping infinitely. What am I?

A. TTL
B. IHL
C. Fragment Offset
D. Protocol

**Answer:** A

AI Analyzing: The Time To Live (TTL) field is decremented by each router to prevent infinite loops.
